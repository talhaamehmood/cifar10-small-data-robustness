# CIFAR-10 with 500 Images: Robustness to Distribution Shift

Deep Learning for Perception (Fall 2026) – Assignment 2, Section B.

Train an image classifier **from scratch** on only 500 CIFAR-10 images (50 per class) and make it work on a
**shifted test set** (rotation ±25°, brightness/contrast changes, ~25% occlusion, plus a hidden corruption).

## Constraints
- No pretrained weights, ≤ 1,000,000 trainable parameters
- At least one Inception-style module (parallel 1×1 / 3×3 / 5×5 branches with 1×1 reductions)
- 400 train / 100 validation split; all hyper-parameters chosen on validation only
- On-the-fly augmentation on training data only; ≤ 60 epochs; 3 seeds, reported as mean ± std

## Approach
- **Model:** conv-BN-ReLU stem → 3 Inception modules → global average pooling → FC → Dropout → FC
- **Augmentation:** random crop + horizontal flip, rotation ±25°, colour jitter, blur, noise, Cutout,
  Mixup/CutMix with label smoothing, random grayscale / channel permutation (colour robustness)
- **Regularisation:** BatchNorm, dropout after the FC layer, weight decay, warm-up + cosine LR, early stopping on validation
- **Extras:** ablation study (Part D), error analysis (Part E), test-time augmentation (Part F, bonus)

## How to run
**Google Colab (easiest):** open the notebook, set Runtime → GPU, then Run all (~15–30 min on a T4).

**Locally:**
```bash
pip install -r requirements.txt
jupyter notebook notebooks/cifar10_small_data_robustness.ipynb
```
CIFAR-10 is downloaded automatically. If you have the official `train_small`, `shifted_test` and `clean_test`
files, set their paths in the `PROVIDED` dict in the data cell; otherwise the notebook builds its own approximate
shifted test set.
